# GenOps v3.1.0

> Native, in-repo, zero-dependency specification pipeline engine for AI coding agents.

## Highlights

- **`genops doctor`** — one command runs all four governance gates (validate, check-rules, drift, verify) and reports a consolidated pass/fail.
- **`genops demo`** — scaffolds a throwaway module and verifies it, proving the full `PRD → HLD → ADR → LLD → Code` pipeline end-to-end in seconds.
- **`genops --version`** and a real `__version__` surfaced through the MCP `serverInfo`.

## Reliability & correctness

- **Deterministic hashing** now excludes `__pycache__/`, `*.pyc`, virtualenvs, `node_modules`, and build output — restoring true cross-platform LF-normalized SHA-256 state tracking.
- **`default_files`** in scaffold `STRUCTURE.yaml` are now actually generated (previously declared but ignored).
- **Brownfield ingestion** skips `__pycache__` and build directories.
- **`impact`** traversal honors both `upstream_refs` and `downstream_refs` and uses an O(n) queue.
- **Frontmatter parser** supports indented multi-line lists and fails loudly on unsupported YAML instead of silently corrupting the document index; `validate` warns on unsupported JSON-Schema keywords.
- **Root discovery** errors cleanly when run outside a project.

## Verification & tooling

- **`verify`** now covers Python syntax, Go vet+build, Rust `cargo check`, TypeScript `tsc --noEmit`, and optional `ruff` — skipping gracefully when a toolchain is absent.
- **CI** gains an `examples-gate` job that runs the Python example's 26 tests and both Go microservice suites.
- **`install_global.py`** is now portable (self-locating, `Path.home()`-relative, `sys.executable` for MCP, JSON backup).

## Examples (now the golden path)

- **`examples/url-shortener`** — a runnable FastAPI service with clean/hexagonal architecture, SSRF-hardened domain, API-key auth, and click analytics (26 passing tests).
- **`examples/url-shortener-cluster`** — Go microservices modeling a Redis/Kafka/ClickHouse design with mocked adapters and concurrency tests.

## Hygiene

- Removed tracked bytecode, stale state files, and `TEMP.md`; hardened `.gitignore`; made the pre-commit hook executable; renamed the misleading `domain_count` state field to `file_count`.

# GenOps v3.1.1

> End-to-end dogfooding fixes for transitive staleness, verification accuracy, and Windows UTF-8 BOM tolerance.

## Summary of Fixes

1. **Transitive staleness propagation** — `genops status` propagates staleness down the full `PRD → HLD → ADR → LLD → code` chain instead of stopping at direct children.
2. **Accurate compiler verification reporting** — `genops verify` distinguishes actually executed compiler checks from skipped toolchains.
3. **UTF-8 BOM tolerance** — Frontmatter and YAML parsers strip leading BOM markers written by Windows tooling (`utf-8-sig`).
4. **Cascade-ordered impact reports** — `genops impact` orders downstream specifications in cascade stage order (`HLD → ADR → LLD`).
5. **Dead template removal** — Removed unused `code/CODE-domain.md.template` because the `code` stage scaffolds directly into `src/`.

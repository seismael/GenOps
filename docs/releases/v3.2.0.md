# GenOps v3.2.0

Release focused on zero-dependency standards compliance, federated & monorepo scale, bidirectional AST/SQL anti-drift, SARIF CI integration, and multi-domain dogfooding.

## Highlights

- **Modular Zero-Dependency Engine (`.agents/scripts/genops_engine/`)**: Cleanly separated `yaml_parser.py`, `schema.py`, `antidrift.py`, `sarif.py`, and `workspace.py` behind `.agents/scripts/genops.py` while remaining 100% Python 3.8+ standard-library-only.
- **Full YAML 1.2 Core & JSON Schema Draft-07 Core**: Supports block scalars (`|`, `>`), nested flow collections, anchors/aliases, `$ref`, `patternProperties`, `dependencies`, `multipleOf`, `not`, `if`/`then`/`else`, and `format` validators.
- **Federated Lineage & Monorepo Orchestration**: Cross-repo `ext://<alias>/<SPEC-ID>` resolution via `pipeline.federation.remotes`, plus `genops workspace {status,doctor}`, `genops explain <stage>`, `--sarif` (OASIS SARIF 2.1.0), and `genops rotate-events`.
- **AST, SQL Contract & Bidirectional Anti-Drift**: Python `ast.parse` + comment-stripped symbol verification, SQL `CREATE TABLE` DDL parity, and `.genopsignore`-aware reverse-module checks.
- **Security & Performance Hardening**: Shell/Batch/PowerShell launcher escaping in `install_global.py`, symlink-escape & `--` argument-injection guards, UTF-8 byte-accurate MCP `Content-Length` framing, `mtime_ns`-keyed config/spec caching, and $O(1)$ event-log tail seeking.
- **Multi-Domain Reference Examples**: Added [`examples/ledgerflow`](../../examples/ledgerflow) and [`examples/pulsegate`](../../examples/pulsegate), passing all governance gates and unit test suites.
